# Design goals for core system rewrite

- Don't use weird-ass vcap system. Just export objs.
  
  - Forget about i-frames and dimension swapping; just split into multiple replays. It's not like Blender would like that anyway.
  
  - Every chunk that was loaded at any point gets saved.

- Use MTL file w/ extensions rather than custom material format.
  
  - Additional "flags" can specify data for a plugin to use, but the base format should be compatible.

- Animations on a per-tick basis rather than a per-frame basis.
  
  - Tick stride option for timelapses.

- Avoid using NBT. Dense data shall use a standalone binary format, and metadata goes in json.

- Mod should be standalone; replay mod and flashback integration are optional.

- **Optional:** FBX exporter (although use OBJs during capture for simplicity)

- In-memory representation should mirror on-disk representation. If another format is needed during generation, convert to final data structure *before* saving to disk.
