# Public capture contribution

This branch starts from the public `mc26.3` baseline and contains reusable capture/Blender features only.
- Push this branch only to public `origin` (`DragonbornElric/mc-world-export`).
- Do not copy private commit history, Emma adapters, server companions, assets, recordings, deployment manifests or local machine configuration.
- Preserve the independently installed private build and its rollback backups.
- Keep generated test worlds, audio, textures, replays and Blender scenes under ignored `build/`.
- Preserve LICENSE and original-project attribution.
